# Book Appointment RESTful API 🚀

A robust, lightweight RESTful API built with **Python** and **Flask** for managing appointments. This project implements full **CRUD** (Create, Read, Update, Delete) operations with clean endpoint structuring.

---

## 🛠️ Tech Stack
* **Language:** Python
* **Framework:** Flask
* **Tooling & Testing:** Postman

---

## 📌 API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| **GET** | `/appointments` | Retrieve all scheduled appointments |
| **POST** | `/appointments` | Create a new appointment |
| **PUT** | `/appointments/<id>` | Update an existing appointment by ID |
| **DELETE** | `/appointments/<id>` | Delete an appointment by ID |
